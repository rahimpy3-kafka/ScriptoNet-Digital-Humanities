
# Project Roadmap

## ScriptoNet: AI-Assisted Detection and Mapping of Therapeutic Processes in Literary Fiction

This roadmap describes the planned development of ScriptoNet from conceptualisation to an AI-assisted Digital Humanities research framework.

---

# Phase 1: Research Foundation

## Objective

Develop a strong theoretical and methodological foundation.

## Activities

- Define research questions
- Study Digital Humanities approaches
- Review Medical Humanities literature
- Study narrative theory and therapeutic representation
- Define therapeutic mechanism categories

## Expected Output

- Research framework
- Literature review
- Annotation guidelines

Status:

✅ In Progress

---

# Phase 2: Literary Corpus Preparation

## Objective

Create a suitable literary dataset for computational analysis.

## Activities

- Select literary works
- Collect publicly available texts
- Prepare metadata
- Convert texts into machine-readable format

Dataset information:

- Author
- Title
- Chapter
- Passage text
- Metadata

## Expected Output

A structured literary corpus.

Status:

⬜ Planned

---

# Phase 3: Text Processing and Annotation

## Objective

Create labelled examples for machine learning.

## Activities

- Divide novels into meaningful passages
- Develop annotation guidelines
- Identify therapeutic representations
- Classify therapeutic mechanisms
- Assign intensity levels

Annotation categories:

- Scriptotherapy
- Poetry-mediated Processing
- Music-mediated Processing
- Narrative Reconstruction
- Emotional Catharsis

## Expected Output

An annotated literary dataset.

Status:

⬜ Planned

---

# Phase 4: Baseline Computational Models

## Objective

Develop initial computational experiments.

## Activities

Implement traditional machine learning approaches:

- TF-IDF feature extraction
- Logistic Regression
- Support Vector Machines
- Random Forest

Purpose:

Establish a baseline performance before advanced AI models.

## Expected Output

- Baseline results
- Error analysis
- Identification of limitations

Status:

⬜ Planned

# Phase 5: Advanced NLP Models

## Objective

⬜ Planned
